Efe Gündoğdu - Personal Portfolio Website

Link: https://efe-gundogdu-portfolio.netlify.app/

[TR]

Bu proje, **HTML**, **CSS** ve **JavaScript** kullanılarak geliştirilmiş modern ve duyarlı (responsive) bir kişisel portfolyo web sitesidir. Web sitesi; kişisel bilgilerimi, deneyimlerimi, becerilerimi ve iletişim bilgilerimi kullanıcı dostu bir tasarımla sunmaktadır.

[EN]

This is a responsive and modern personal portfolio website built with **HTML**, **CSS**, and **JavaScript**. The website showcases my background, skills, and contact information in a clean and user-friendly layout.

Özellikler / Features

[TR]

- Tüm cihazlar için duyarlı (responsive) tasarım
- Mobil cihazlar için hamburger menü navigasyonu
- Hakkımda, Deneyim ve İletişim bölümleri
- CV indirme ve sosyal medya bağlantıları

[EN]

- Responsive design for desktop, tablet, and mobile
- Hamburger menu for mobile navigation
- Section-based layout (About, Experience, Contact)
- Downloadable CV and social media links

Kullanılan Teknolojiler / Technologies Used

- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (DOM manipulation)
